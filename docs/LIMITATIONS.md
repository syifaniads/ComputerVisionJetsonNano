# Limitations

- The public evidence supports a MobileNetV2 ONNX **classifier**, not bounding-box object detection.
- No retained reproducible Jetson Nano latency/FPS benchmark is available.
- No CUDA/TensorRT execution-provider evidence is claimed.
- Camera I/O and Jetson runtime compatibility are hardware/OS dependent and cannot be validated by hosted GitHub Actions.
- An ImageNet classifier is not a task-specific robotics perception model.
- The portfolio refactor adds software-engineering structure after the original 2025 experiment; those additions are not presented as historical execution evidence.
